# `L2` — File naming conventions

**Principle:** L — Locatability

Raised by the Consequences compiler plugin when a file's name does not
match a documented naming convention.

## Cause

Consequent Style uses a small set of file-name conventions: types live in
files named after the type, package-level givens live in
`<package>_<scope>.scala` files, and so on. Names outside this set
are rejected.

## Example message

```
[↯L2] file name `helpers.scala` does not match a documented naming convention
```

## Resolution

Rename the file to match the convention for its content kind. See
the Consequences documentation for the full list of permitted patterns.
