# `F1` — Licence-header block comment

**Principle:** F — The Frame

Raised by the Consequences compiler plugin when the licence-header block
comment is missing or malformed.

## Cause

Every source file opens with a `/* … */` licence header occupying the
first `header` lines — 32 by default. Line 1 must contain `/*` and
line `header` must contain `*/`.

Setting `-P:consequences:header=0` disables this rule, for a project
that has no licence header.

## Example message

```
[↯F1] line 1 must open the license-header block comment with `/*`
```

```
[↯F1] line 32 must close the license-header block comment with `*/`
```

## Resolution

Copy the project's licence header verbatim from another source file.
